# Tools Module Reference

This directory contains the base tool structure and built-in tools for the agents to extend their capabilities.

## File: `base_tool.py`
The [base_tool.py](file:///d:/koding/codes/Machine%20Learning/projects/MAS/tools/base_tool.py) file defines the **`BaseTool`** abstract class. Every custom tool you create must inherit from this class to guarantee a standard interface that agents and LLMs can interact with.

---

## 1. Class: `BaseTool` (Inherits from `abc.ABC`)
An abstract base class (ABC) that serves as the blueprint for all tools.

### Constructor: `__init__`
Initializes a tool instance with a name and a description.

#### Parameters & Instance Variables
| Variable | Scope | Type | Purpose |
| :--- | :--- | :--- | :--- |
| `name` | Parameter / Instance (`self.name`) | `str` | A short identifier for the tool (e.g., `"calculator"`, `"web_search"`). The LLM uses this name to specify which tool it wants to execute. |
| `description` | Parameter / Instance (`self.description`) | `str` | A plain English explanation of what the tool does, its inputs, and its output format. The LLM reads this description to decide when to call the tool. |

---

### Abstract Methods

#### `run(input_text)` (Decorated with `@abstractmethod`)
* **Purpose:** Executes the core function of the tool. Every subclass **must** implement this method; otherwise, Python will raise a `TypeError` when attempting to instantiate the class.
* **Parameters & Returns:**
  * `input_text` (Parameter - `str`): The query, expression, or arguments generated by the LLM. It is always a string, even if representing structured data like JSON or numbers.
  * **Returns** (`str`): The response output of the tool execution, which is injected back into the LLM's context.

---

### Utility Methods

#### `to_dict()`
* **Purpose:** Formats the tool's details into a dictionary object. This is used by the agent to construct instructions explaining available tools to the LLM.
* **Returns:** A dictionary containing:
  * `"name"`: The string identifier.
  * `"description"`: The explanation string.

#### `__repr__()`
* **Purpose:** Returns a clean string representation of the tool object (e.g., `Tool(name='calculator')`), useful for debugging.

## ## File: `builtin_tools.py`
The [builtin_tools.py](file:///d:/koding/codes/Machine%20Learning/projects/MAS/tools/builtin_tools.py) file contains pre-implemented tools that can be registered on any agent.

### 1. `CalculatorTool`
Safely evaluates mathematical expressions using Python's `ast` (Abstract Syntax Tree) module instead of the dangerous `eval()` function.

#### Methods & Internal Functions:
* **`__init__()`**
  * Registers name `"calculator"` and details support for `+`, `-`, `*`, `/`, `//`, `%`, `**`, `()`.
* **`run(input_text)`**
  * Parses `input_text` using `ast.parse` and evaluates it recursively via `_eval_node`.
* **`_eval_node(node)`**
  * Recursively walks through AST nodes. Supported nodes: `ast.Constant` (numbers), `ast.BinOp` (binary math), `ast.UnaryOp` (signed numbers).

#### Variables:
| Variable | Scope | Type | Purpose |
| :--- | :--- | :--- | :--- |
| `_OPERATORS` | Class Variable | `dict` | Maps AST operator classes (e.g., `ast.Add`) to Python operator functions (e.g., `operator.add`). |
| `expression` | Local in `run` | `str` | Stripped input string. |
| `tree` | Local in `run` | `ast.Expression` | Compiled syntax tree representation of the expression. |
| `result` | Local in `run` / `_eval_node` | `int` / `float` | Calculated numeric output. |
| `node` | Parameter in `_eval_node` | `ast.AST` | The current syntax node being evaluated. |

### 2. `WebSearchTool`
Searches the web using DuckDuckGo's HTML-only interface, avoiding rate limits by parsing standard HTML instead of the private JSON API endpoints.

#### Methods:
* **`__init__(max_results=3)`**
  * Sets the result limit and names the tool `"web_search"`.
* **`run(input_text)`**
  * Fetches `https://html.duckduckgo.com/html/?q=...` with a browser `User-Agent`. Parses the result page using `BeautifulSoup`, extracts the text title and snippet, and parses out the real destination URL from DuckDuckGo's redirection link using `urllib.parse`.

#### Variables:
| Variable | Scope | Type | Purpose |
| :--- | :--- | :--- | :--- |
| `self.max_results` | Instance | `int` | Maximum search results to return. |
| `query` | Local in `run` | `str` | Cleaned search keywords. |
| `url` | Local in `run` | `str` | The URL-encoded query address pointing to DuckDuckGo HTML search. |
| `max_retries` | Local in `run` | `int` | Maximum number of search attempts (default is 3). |
| `attempt` | Local loop in `run` | `int` | Current retry iteration index. |
| `res` | Local in `run` | `Response` | The HTTP response object containing the HTML search page. |
| `soup` | Local in `run` | `BeautifulSoup` | Parsed HTML object representation of the page. |
| `divs` | Local in `run` | `list[Tag]` | HTML container elements holding individual search results. |
| `output_lines` | Local in `run` | `list[str]` | Lines of formatted search text to join and return. |

### 3. `FileReaderTool`
Reads text files from local disk. It restricts reads to a designated root directory for security and caps reads at 8000 characters.

#### Methods:
* **`__init__(allowed_dir=".")`**
  * Names the tool `"read_file"` and resolves `allowed_dir` to its absolute path.
* **`run(input_text)`**
  * Cleans the requested path, checks if it is within `allowed_dir`, reads up to 8000 characters, and appends a warning if truncated.

#### Variables:
| Variable | Scope | Type | Purpose |
| :--- | :--- | :--- | :--- |
| `self.allowed_dir` | Instance | `str` | Absolute path of the directory the agent is restricted to read from. |
| `file_path` | Local in `run` | `str` | Stripped relative/absolute file path requested by the LLM. |
| `full_path` | Local in `run` | `str` | Fully resolved absolute path of the target file. |
| `max_chars` | Local in `run` | `int` | Maximum characters to read (hardcoded to 8000). |
| `content` | Local in `run` | `str` | Extracted text from the file. |
| `full_size` | Local in `run` | `int` | Size of the file in bytes. |

---

### 4. `DateTimeTool`
Provides current date, time, and day of week. Useful for time-sensitive tasks.

#### Methods:
* **`__init__()`**
  * Names the tool `"get_datetime"`.
* **`run(input_text)`**
  * Disregards the input and returns a formatted date/time string.

#### Variables:
| Variable | Scope | Type | Purpose |
| :--- | :--- | :--- | :--- |
| `now` | Local in `run` | `datetime.datetime` | Captured current local timestamp object. |
